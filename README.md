# GPS-трекер → Google Таблица

Веб-приложение в браузере (телефон/ПК) записывает GPS-координаты и отправляет их
в Google Таблицу через Apps Script Web App.

**🌐 Приложение в сети: https://kedzh.github.io/gps-tracker/index.html**
(открывайте на телефоне — только там есть GPS; после открытия введите URL
Apps Script в настройках, они сохранятся в браузере этого телефона)

**Что записывается:** время, широта, долгота, точность, скорость (м/с и км/ч),
высота, курс, метка, имя устройства. Есть режим «непрерывный трек» с настраиваемым
интервалом и фильтром по точности.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Само приложение (один файл, ничего не собирать) |
| `Code.gs` | Скрипт для Google Apps Script (приём данных) |

## Настройка за 5 минут

### 1. Создайте таблицу
Откройте [sheets.new](https://sheets.new) — создастся пустая Google Таблица.

### 2. Вставьте скрипт
**Расширения → Apps Script**. Удалите содержимое `Code.gs` и вставьте файл
`Code.gs` из этой папки. Измените строку:

```js
const TOKEN = 'school-2026';   // придумайте свой пароль
```

→ **Сохранить** (иконка дискеты).

### 3. Опубликуйте веб-приложение
**Развернуть → Новое развёртывание → ⚙ → Тип: Веб-приложение**

- Описание: `gps-tracker`
- Выполнять от: **Мой аккаунт (Я)**
- Доступ: **Все**

→ **Развернуть** → разрешите доступ → **Скопируйте URL**
(вида `https://script.google.com/macros/s/…/exec`).

Проверка: откройте скопированный URL в браузере — должна появиться строка
`{"ok":true,"app":"gps-tracker",...}`.

### 4. Настройте приложение
Откройте `index.html` в браузере (двойной клик по файлу) и заполните:

- **URL веб-приложения** — скопированный из шага 3
- **Секретный токен** — тот же, что в `Code.gs`
- **Ссылка на Google Таблицу** — адрес самой таблицы
- **Имя устройства** и **Метка** — подпись точек
- **Интервал трека** — например, 15 сек
- **Порог точности** — например, 50 м (метки хуже отбрасываются)

Нажмите **💾 Сохранить настройки**.

### 5. Работа
- **➕ Записать точку** — одна текущая метка в таблицу;
- **▶ Старт трек** — запись каждые N секунд, пока кнопка активна;
- **■ Стоп** — закончить трек;
- Данные уходят автоматически. Если интернета нет — точки копятся в браузере
  (`Очередь`) и отправляются при появлении связи.

## Как открыть приложение на телефоне

Геолокация работает только по **HTTPS** (или локально). Варианты:

1. **Хостинг (рекомендуется)** — положите `index.html` в репозиторий GitHub и
   включите Pages (Settings → Pages → main), получите адрес
   `https://<user>.github.io/<repo>/index.html` и откройте его на телефоне.
   Можно также разместить на школьном сайте в папке.
2. **Локально** — просто откройте файл на ПК с GPS (Chrome считает `file://`
   безопасным контекстом). На телефоне такой файл по прямой ссылке обычно
   не открывается.

На телефоне при первом запуске браузер спросит разрешение на доступ к
геолокации — нажмите **Разрешить**. Для точного трека включите GPS
(«Высокая точность» в настройках телефона).

## Если данные не приходят

| Причина | Что делать |
|---|---|
| `Неверный токен` | Токен в приложении ≠ `TOKEN` в Code.gs |
| `Failed to fetch` / CORS | Проверьте, что URL заканчивается на `/exec`, а не `/dev`; перевыпустите развёртывание с доступом «Все» |
| `HttpError: 401/403` | В развёртывании «Выполнять от: Я», доступ «Все» |
| Точки в очереди, но не в таблице | Нажмите «🔄 Отправить сейчас», проверьте интернет |
| «URL не задан» | Вставьте URL в настройках и нажмите «Сохранить» |

## Хранение данных

- Настройки и неотправленные точки хранятся в `localStorage` браузера
  (остаются после перезагрузки, но привязаны к устройству и браузеру).
- Вся история — в Google Таблице, лист **GPS**.
